# UI Review: Karten und Ausrichtung

Status: in Bearbeitung

## Prüfpunkte

- [x] Referenzprojekte: Pfeile auf Titelhöhe; lange Projektnamen dürfen umbrechen.
- [x] Leistungen: Fachbereichstitel zentrieren; Service-Titel neben dem Icon auf gleicher Höhe zentrieren (Desktop und Mobil).
- [x] Kennzahlen: Zahl zentriert direkt über der Beschriftung.
- [x] Stellenangebote: Jobkarten linksbündig bzw. mit passender Mischung aus linksbündigen Metadaten und Text.
- [x] Vorteile: Icon und Text in einer gemeinsamen Kartenzeile.
- [x] „Für wen wir arbeiten“: Icon und Text in einer gemeinsamen Kartenzeile.
- [x] Kontaktinfo: E-Mail bis Fax linksbündig.
- [x] Anfrageformular: passende Beschriftungen und Auswahltexte linksbündig; Bewerbungsseite bleibt zentriert.
- [x] Gesamtprüfung: Hauptseiten, Stellen- und Bewerbungsvarianten auf Mobil/Desktop ohne Seitenüberläufe.

## Testansichten

- Mobil: 320 × 640 und 390 × 844.
- Desktop: 1280 × 900.
- Zertifikate bleiben innerhalb ihrer horizontal wischbaren Leiste.
